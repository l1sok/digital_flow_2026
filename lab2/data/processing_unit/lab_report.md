`data_a[0]` - это входной порт, он поступает на регистр напрямую. Fanout = 23, значит к этому порту подключено еще 23 провода, дающие нагрузку 181.1 фФ. Arrival = 2ns, мы задали это в SDC.

`mul_30_55_g7766__1881/Y` - это выход мультиплексора. Тут путь от входа к выходу. Fanout = 3, значит к Y подключено еще 3 провода, дающие нагрузку 25.4 фФ.
Предположение, что Load, Trans, Delay задаются в .lib. Arrival тут складывается из внутренней задержки ячейки + входной задержки из SDC.
На выходе происходит спад (Edge = F).

Slack = Required Time - Arrival Time

```
Required Time := 9.871
Input Delay   :- 2.000
Data Path     :- 6.921

Slack         := 0.950
```
Arrival Time - время распространения + задержка входа (2нс)

Arrival Time = Input Delay + Data Path = 8.921
Slack = 9.871 - 8.921 = 0.95

В отчете есть прекрасное слово MET, то есть временное ограничение выполнено. Слак положительный, так что все логично, у нас в запасе осталось время.

# Задание 2. Расчет задержек по таблицам библиотеки

## Определение направления перехода на входе и выходе каждого инвертора

Рассматриваются два пути:

- `X → INV1 → INV2 → Y`
- `X → INV1 → INV3 → Z`

Инвертор изменяет направление перехода сигнала на противоположное: нарастающий фронт (`0 → 1`) преобразуется в спадающий (`1 → 0`).

Поскольку выход INV1 подключен ко входам INV2 и INV3, оба инвертора второго каскада получают одинаковое направление фронта, противоположное исходному фронту X.

| Инвертор | Вход | Выход |
|---|---|---|
| INV1 | Rise | Fall |
| INV2 | Fall | Rise |
| INV3 | Fall | Rise |

## Рассчитайте нагрузку на выходах INV1, INV2 и INV3. Для выхода INV1 учтите оба подключенных приемника.

Нагрузка на выходе логического элемента определяется суммой входных ёмкостей всех подключенных к выходу элементов.

Входная ёмкость одного инвертора: C_A = 0.0028869 пФ. значит:

C_INV1 = 2*C_A = 0.0057738 пФ
C_INV2 = C_L = 0.03 пФ
C_INV3 = C_Z = 0.05 пФ

## Выберите таблицы задержки и выходного transition для соответствующего направления выходного перехода.

Для выходных пинов инвертора:
INV1 Y -> fall -> cell_fall и fall_transition
INV2 Y -> rise -> cell_rise и rise_transition
INV3 Y -> rise -> cell_rise и rise_transition
